# Diamond Centre - Web

Frontend web application for Diamond Centre conference management.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Prerequisites

- Node.js >= 18

## Installation

```bash
npm install
cp .env.example .env
npm run dev
```

## Scripts

| Script           | Description       |
| ---------------- | ----------------- |
| `npm run dev`      | Development       |
| `npm run build`    | Production build  |
| `npm start`        | Start production  |
| `npm run lint`     | Lint code         |
| `npm run typecheck`| TypeScript check  |

## Branches

| Branch   | Description    |
| -------- | -------------- |
| main     | Production     |
| test     | Pre-production |
